Integration Guide for Responsive Game Interface

📋 Tổng Quan / Overview

Bộ thành phần UI mới được thiết kế hoàn toàn từ đầu để cung cấp:

  • Giao diện hiện đại và tối giản (Modern & Minimalist)
  • Hỗ trợ đầy đủ responsive (Mobile, Tablet, PC, Mac)
  • Dễ bảo trì và mở rộng (Maintainable & Extensible)
  • Tuân thủ tiêu chuẩn accessibility (WCAG 2.1)
  • Tối ưu hiệu suất cao (High Performance)

🚀 Bước Tích Hợp / Integration Steps

1 Thêm CSS Stylesheet
<link rel="stylesheet" href="public/game-ui.css">

Thêm dòng này vào thẻ <head> của HTML

2 Import Components vào MainMenuScene
import { GameModeSelector } from "./ui/GameModeSelector.js"; import { GameUIOverlay } from "./ui/GameUIOverlay.js"; import GameModeRegistry from "./gameModes/GameModeRegistry.js";
3 Tạo Components trong create() method
create() { const overlay = new GameUIOverlay(this); overlay.createGameStartUI(); const selector = new GameModeSelector(this, { modes: GameModeRegistry.getAll(), onStartGame: () => { this.scene.start("PlanningScene", { mode: selector.selectedMode }); } }); selector.create(); }
4 Cleanup trong shutdown() method
shutdown() { this.selector?.destroy(); this.overlay?.destroy(); }

✨ Best Practices

Quản Lý Vòng Đời

create() { this.selector = new GameModeSelector(this, {...}); this.selector.create(); } shutdown() { this.selector?.destroy(); }
update() { // KHÔNG TẠO MỚI UI // TẠI ĐÂY - CHẬM! new GameModeSelector(this, {...}); }

Responsive Handling

this.scale.on('resize', (size) => { this.overlay?.updateForScreenResize( size.width, size.height ); });
this.scale.on('resize', () => { // KHÔNG TẠO MỚI this.selector = new GameModeSelector(...); });

Callback Functions

onModeSelected: (id) => this.handleMode(id),
onModeSelected: function(id) { // 'this' sẽ bị mất }

📱 Responsive Breakpoints

Tablet 481px - 768px 0.9x Font vừa, layout 1-2 cột

📚 API Reference

GameModeSelector Methods

  • create() - Tạo UI elements
  • show() - Hiển thị selector
  • hide() - Ẩn selector
  • toggle() - Bật/Tắt hiển thị
  • selectMode(id) - Chọn chế độ
  • selectDifficulty(id) - Chọn độ khó
  • refresh() - Cập nhật UI
  • destroy() - Xóa components

GameUIOverlay Methods

  • createGameStartUI() - Tạo giao diện bắt đầu
  • createToast(msg, duration, type) - Hiển thị thông báo
  • createLoadingScreen() - Màn hình tải
  • updateForScreenResize(w, h) - Cập nhật resize
  • destroy() - Xóa tất cả elements

🔧 Troubleshooting

❌ Vấn đề: Giao diện không hiển thị

✓ Giải pháp:

  • Kiểm tra CSS file được load (public/game-ui.css)
  • Kiểm tra components được tạo trong create()
  • Kiểm tra depth value (nên ≥ 1000)
❌ Vấn đề: Nút không click được

✓ Giải pháp:

  • Đảm bảo setInteractive() được gọi
  • Kiểm tra pointer events không bị block
  • Kiểm tra canvas pointer-events CSS
💡 Tip: Sử dụng Phaser DevTools hoặc browser console để debug

✅ Testing Checklist

  • Kiểm tra trên mobile (< 480px)
  • Kiểm tra trên tablet (481-768px)
  • Kiểm tra trên desktop (> 768px)
  • Kiểm tra landscape & portrait modes
  • Kiểm tra touch interactions
  • Kiểm tra keyboard navigation
  • Kiểm tra screen reader (accessibility)
  • Kiểm tra FPS (60 desktop, 30-45 mobile)
  • Kiểm tra memory leaks (shutdown)
  • Kiểm tra dark mode compatibility
