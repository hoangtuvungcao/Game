Create Button:
  ModernUIEnhancer.createButton(scene, x, y, w, h, label, onClick, options)

Create Card:
  ModernUIEnhancer.createCard(scene, x, y, w, h, options)

Create Radio Group:
  ModernUIEnhancer.createRadioGroup(scene, x, y, options)

Show Notification:
  ModernUIEnhancer.showNotification(scene, message, options)

  new GameModeUIPanel(scene, options)

Get Responsive Sizes:
  ModernUIEnhancer.getResponsiveSizes(scene)
